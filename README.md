# Мини-курс «5 шагов к осознанной работе с ИИ-кодом»

Статический образовательный сайт на русском языке о безопасной и осмысленной работе с генеративным ИИ при разработке программного обеспечения. Курс состоит из последовательных модулей с теорией, практическими заданиями, редактируемыми фрагментами JavaScript и тестами.

## Возможности

- Пять учебных модулей, между которыми можно переходить стрелками по краям экрана.
- Нелинейная навигация: на первом модуле недоступен переход назад, на последнем — вперёд.
- Автоматическая прокрутка к началу страницы при смене модуля.
- Раскрываемые подсказки и разборы заданий.
- Редакторы кода с нумерацией строк, горизонтальной и вертикальной прокруткой.
- Подсветка только изменённых фрагментов кода относительно исходного варианта.
- Отдельная подсветка добавленных строк и возможность сбросить редактор к исходному состоянию.
- Тесты из пяти вопросов с проверкой ответов и сбросом результатов. Сейчас тесты заполнены в модулях 1 и 2.
- Адаптивная тёмная интерфейсная тема для компьютеров и мобильных устройств.

## Темы курса

1. Как работает ИИ-ассистент, его сильные стороны, галлюцинации и ограничения.
2. Как составлять качественные промпты для задач разработки.
3. Как проверять и исправлять код, полученный от ИИ.
4. Риски использования ИИ: безопасность, лицензии и ответственность.
5. Итоговая практика по работе с ИИ-кодом.

## Запуск

Проект не использует зависимости и этап сборки. Для быстрого просмотра достаточно открыть `index.html` в современном браузере.

Для разработки удобнее запустить локальный статический сервер из корня проекта. Например, при установленном Node.js:

```bash
npx serve .
```

После запуска откройте адрес, который выведет команда, обычно `http://localhost:3000`.

## Как устроена интерактивность

### Навигация по модулям

Каждый модуль — это элемент `<article class="module-card">`. Скрипт показывает только один модуль одновременно. Переход доступен через кнопки-стрелки слева и справа, а также кликом в крайние зоны экрана.

### Редактор кода

Блок с атрибутом `data-code-sample` получает интерактивный редактор автоматически. Исходный текст сохраняется при загрузке страницы. При вводе скрипт сравнивает текущий текст с исходным:

- изменённые символы подсвечиваются непосредственно в строке;
- добавленный текст и новые строки выделяются;
- неизменённые строки после вставки не считаются изменёнными;
- кнопка `Reset` возвращает исходный код.

Текущая реализация предназначена для демонстрации изменений, а не для выполнения JavaScript-кода: введённый код не запускается и никуда не отправляется.

### Тесты

Тест определяется контейнером `data-quiz`, а каждый вопрос — `data-quiz-item`. Правильный вариант задаётся атрибутом `data-correct`, например:

```html
<div class="quiz__item" data-quiz-item data-correct="b">
```

Кнопка «Проверить ответы» выводит итоговый счёт, а «Сброс» очищает выбранные ответы. Результаты не сохраняются между перезагрузками страницы.

## Добавление нового модуля

1. Добавьте в `index.html` новый `<article class="module-card" id="module-N" hidden>`.
2. Разместите внутри учебный текст в прямых дочерних `<div>` — стили автоматически оформят их как отдельные подблоки.
3. Для практики добавьте разметку редактора с `data-code-sample`, `data-code-input`, `data-code-overlay`, `data-code-lines` и кнопкой `data-code-reset`.
4. При необходимости добавьте тест с пятью элементами `data-quiz-item` и кнопками `data-quiz-check` / `data-quiz-reset`.
5. Навигация автоматически подхватит новый модуль: количество карточек определяется в JavaScript при загрузке страницы.

## Ограничения и дальнейшее развитие

- В проекте пока нет автоматических тестов.
- Нет сборщика, линтера и форматтера — сайт работает на нативных HTML, CSS и JavaScript.
- Состояние редакторов, раскрытых подсказок и тестов не сохраняется после обновления страницы.
- Подсветка редактора рассчитана на небольшие учебные фрагменты: сравнение строк выполняется в браузере при каждом вводе.

В качестве следующих улучшений можно добавить заполненные тесты для модулей 3–5, сохранение прогресса в `localStorage`, доступную клавиатурную навигацию между модулями и автоматические проверки логики редактора.
